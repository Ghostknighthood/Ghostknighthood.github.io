# BrochOnWheels GitHub Pages

1. Create a public GitHub repository named `USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. GitHub: Settings → Pages → deploy from the main branch.
4. Later, add `broch.be` as the custom domain in Pages and update DNS at your domain provider.

Put the real photos in `images/`. Name the hero photo `hero.jpg` to use it automatically as the large header background.
